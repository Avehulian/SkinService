SkinService 1.6.0 for SPT 4.1.6 (SPTushonka 4.1.6)

Install:
  1. Copy BepInEx/plugins/kmyuhkyuk-KmyTarkovApi into <game>/BepInEx/plugins/
  2. Copy BepInEx/plugins/kmyuhkyuk-SkinService into <game>/BepInEx/plugins/
  3. Copy SPT_Runtime/user/mods/kmyuhkyuk-SkinService into <game>/SPT_Runtime/user/mods/

This mod requires KmyTarkovApi 2.0.0 (included). Do not install the old
EFTApi / KmyTarkovApi 1.x versions alongside it.

此模组依赖 KmyTarkovApi 2.0.0（已包含），请勿同时安装旧版 EFTApi / KmyTarkovApi 1.x。
